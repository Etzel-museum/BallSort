# מבחנות

משחק Ball Sort לאנדרואיד, בלי פרסומות, בלי הרשאת אינטרנט ובלי איסוף מידע.
יש בו עברית ואנגלית, ואפשר להחליף שפה בהגדרות.

## התקנה

מורידים את `BallSort.apk` מה-Release בשם **latest** בעמוד המאגר, פותחים אותו בטלפון ומאשרים התקנה.
עדכון מותקן מעל הגרסה הקודמת, וההתקדמות נשמרת.

## איך זה בנוי

- **המשחק עצמו** כתוב ב-HTML/JS, בתיקייה `app/src/main/assets/www`:
  - `core.js` – החוקים, מחולל השלבים והפותר. אין בו DOM.
    הוא נטען גם ל-Web Worker, כך שיצירת שלבים גדולים ורמזים לא מקפיאים את המסך.
  - `gfx.js` – כל הגרפיקה, ובלי אף קובץ תמונה: כדורים וביצים מצוירים ב-canvas
    (ונשמרים בזיכרון), מבחנות ב-SVG, ו-6 רקעים מצוירים ב-SVG עם אנימציות קלות.
  - `i18n.js` – כל הטקסטים, בעברית ובאנגלית. השמות של הביצים והפריטים נמצאים ב-`catalog.js`, בשדה `en`.
  - `catalog.js` – 30 הביצים, דרגות הנדירות, והפריטים (רקעים, מבחנות, סגנונות כדורים).
    כל פריט נקנה במטבעות או נפתח מביצה מסוימת.
  - `app.js` – מסך הבית, מסך המשחק, האנימציות, הכלכלה, האוסף, בקיעת הביצים והשמירה (localStorage).
- **העטיפה לאנדרואיד** (`MainActivity.kt`) היא WebView במסך מלא. הוא טוען את הקבצים מתוך
  ה-APK דרך WebViewAssetLoader, ממקור https קבוע, כדי שהשמירה תישאר יציבה בין הפעלות.
  כפתור "חזור" סוגר חלונות או מוריד כדור מורם, ואם אין מה לסגור הוא מעביר את האפליקציה לרקע.
- **ה-APK נבנה אוטומטית** ב-GitHub Actions בכל דחיפה ל-main, ונחתם במפתח קבוע
  (`app/debug-keystore.jks`, אותו מפתח של RadioAbba) כדי שעדכונים יותקנו בלי למחוק את הגרסה הקודמת.

## שלבים

- כל שלב נוצר מ"זרע" קבוע לפי מספר השלב, כך ששלב N זהה תמיד ובכל מכשיר.
  יש אינסוף שלבים, והם לא תופסים מקום.
- כל שלב נבדק על ידי פותר (weighted A*) לפני שהוא מוצג, כך שתמיד יש לו פתרון.
  אורך הפתרון שהפותר מוצא הוא הסף ל-3 כוכבים ולבונוס.
- הקושי עולה בהדרגה: 3 צבעים בשלב הראשון, 12 צבעים משלב 121, ועד 18 צבעים (20 מבחנות) משלב 601.
  הטבלה המלאה נמצאת ב-`COLOR_STEPS` בקובץ `core.js`.
  מגרסה 2.0, כשמעבירים כדור עוברים איתו כל הכדורים באותו צבע שמתחתיו ברצף, כמה שנכנסים ביעד.
  הפותר, הרמזים והיעד לשלושה כוכבים מחושבים לפי החוק הזה. בגלל זה חלק מהשלבים, בעיקר "השלבים הקשים",
  נראים אחרת מאשר בגרסה 1.0. שלב שהיה באמצע משחק נשמר כמו שהוא.
  בכל שלב שמספרו מסתיים ב-0 (מ-10) יש "שלב קשה", הקשה מבין 3 מועמדים (2 מועמדים מ-15 צבעים ומעלה).
  בכל שלב שמספרו מסתיים ב-5 (מ-25) יש "כדורים נסתרים".
  בכל שלב שמספרו מסתיים ב-3 (מ-23) יש "שלב נשימה" עם צבע אחד פחות.

## כלכלה

| | מחיר |
|---|---|
| סיום שלב (בפעם הראשונה) | +10, ועוד 5 בונוס על פתרון במספר מהלכים שלא עולה על הסף |
| ביטול מהלך | 2 ← 4 ← 8 … (מתאפס בכל שלב) |
| רמז | 5 ← 10 ← 20 … (מתאפס בכל שלב) |
| מבחנה נוספת | 25, פעם אחת בשלב |
| התחלה מחדש | חינם (המונים והמבחנה שנקנתה נשמרים) |
| יתרת פתיחה | 50 |

המחירים מוגדרים בראש `app.js` (`BASE`, `WIN_COINS`, `BONUS_COINS`, `START_COINS`).

## ביצים ואוסף

- כל 10 שלבים שנפתרים בוקעת ביצה. יש 30 ביצים עם שמות, ואחריהן "ביצת זהב" שחוזרת.
- כל ביצה נותנת מטבעות לפי הנדירות שלה:

  | נדירות | מטבעות |
  |---|---|
  | רגילה | 20 |
  | נדירה | 40 |
  | אפית | 80 |
  | אגדית | 150 |

- חלק מהביצים פותחות גם פריטים:

  | ביצה (שלב) | פריט |
  |---|---|
  | 1 (שלב 10) | כדורים בצורת ביצים |
  | 2 (שלב 20) | רקע קניון |
  | 3 (שלב 30) | מבחנת בקבוק |
  | 5 (שלב 50) | רקע זוהר צפוני |
  | 7 (שלב 70) | אבני חן |
  | 8 (שלב 80) | מבחנת ספירלה |
  | 10 (שלב 100) | רקע אביב |

- **פריטים לקנייה:**

  | פריט | מחיר |
  |---|---|
  | רקע שקיעה | 150 |
  | רקע מעמקי הים | 200 |
  | מבחנת זהב | 250 |
  | כדורים שטוחים | 100 |
  | כדורים עם סמלים | 150 |

- בשדרוג מגרסה 1.0, רקעים שהוסרו (או שהפכו לפרס מביצה) מוחזרים כמטבעות.
  ביצים שכבר "הגיעו" לפי ההתקדמות מחכות לבקיעה במסך הבית.
